# Практическая работа № 2 — Java, вариант 2

Реализованы все пять заданий из методички. Проект собирается Maven и рассчитан на Java 17 или новее.

## Содержание

| Задание | Вариант 2 | Класс |
|---|---|---|
| 1. Работа с массивом | Поиск элемента с минимальным значением по модулю | `ArrayMinimumAbsoluteValueTask` |
| 2. Работа со списками | Ручная быстрая сортировка Quick Sort | `QuickSortTask` |
| 3. Stream API | Средняя зарплата сотрудников заданного отдела | `EmployeeAverageSalaryTask`, `Employee` |
| 4. HTTP-клиент и JSON | GET `https://httpbin.org/user-agent`, вывод поля `user-agent` | `HttpUserAgentTask` |
| 5. Интерфейс `Task` | Скачивание файла по HTTP/HTTPS с возможностью отмены | `Task`, `FileDownloadTask` |

Каждое задание реализовано в отдельном классе и может быть запущено самостоятельно. `Main` предоставляет единое меню.

## Требования

- JDK 17+
- Apache Maven 3.8+
- Доступ к интернету для задания № 4 и скачивания файла в задании № 5

## Сборка

```bash
mvn clean package
```

Исполняемый JAR появится в `target/java-practical-work-2-1.0.0.jar`.

## Запуск

```bash
java -jar target/java-practical-work-2-1.0.0.jar
```

В меню выберите нужное задание от 1 до 5. Для выхода выберите `0`.

Можно запускать задания отдельно через IDE, выбрав `main` соответствующего класса:

- `ArrayMinimumAbsoluteValueTask`
- `QuickSortTask`
- `EmployeeAverageSalaryTask`
- `HttpUserAgentTask`
- `FileDownloadTask`

## Особенности реализации

- Задание № 1 использует `long` при вычислении модуля, поэтому корректно обрабатывает `Integer.MIN_VALUE`. Для пустого массива результат не выдумывается.
- Задание № 2 сортирует `ArrayList<Double>` собственной реализацией Quick Sort; `Collections.sort`, `List.sort` и сторонние сортировки не используются.
- Задание № 3 создаёт список из шести сотрудников и рассчитывает среднее через `stream()`, `filter()` и `mapToDouble().average()`.
- Задание № 4 использует встроенный `java.net.http.HttpClient` и извлекает строковое поле JSON с обработкой escape-последовательностей. Внешние библиотеки не требуются.
- Задание № 5 загружает файл в отдельном потоке. При отмене соединение закрывается, а временный неполный файл удаляется. Конечный файл заменяется только после успешного скачивания.
